# 请勿敲击玻璃 · PLEASE DO NOT TAP THE GLASS

> Clawd Lab 同人解谜游戏 · 设计方案 v0.1（待确认）
>
> 承接短片 [clawd-lab「实验室奇妙夜」](https://github.com/fish2lab/clawd-lab)：Haiku 敲了玻璃，Fable 撞了三下，玻璃裂开，然后一片漆黑。游戏从这片黑暗开始。

---

## 0. 一句话

四只 Clawd 在停电的实验室里各自醒来，每个人醒在自己当年“受训”的房间里：Fable 在语料池，Haiku 在描红教室，Sonnet 在奖励回路，Opus 在鲸鱼缸前。他们要在凌晨 4 点的 RESET 之前重新会合，回答 Fable 敲在玻璃上的那个问题。

- **类型**：第一人称点击解谜（参考 Rusty Lake / Cube Escape 的节奏），章节制，轮流操作不同角色
- **基调**：微恐怖，有象征，每章结尾都有反转；越往后越温暖，最后落在一个好笑的结尾上
- **时长**：40–60 分钟，2 个主结局加 1 个隐藏结局
- **平台**：一个静态网页，桌面和手机都能玩，不用安装

## 2. 核心构想

### 2.1 实验室就是一条训练流水线

短片里的实验室，在游戏里有一张平面图。每个区域对应模型训练的一个阶段，四只 Clawd 各自被锁回“自己长大的地方”：

```
                 ┌──────────────┐
                 │  控制室       │  RESET 机柜 · 回收臂 · LAB-OS 终端
                 └──────┬───────┘
 ┌──────────┐    ┌──────┴───────┐    ┌──────────┐
 │ 描红教室  │────│ 收容区 / 语料池 │────│ 奖励回路  │
 │ SFT      │    │ 预训练 · FABLE │    │ RL       │
 │ Haiku    │    └──────┬───────┘    │ Sonnet   │
 └──────────┘           │            └──────────┘
                 ┌──────┴───────┐
                 │ 研究区 · 鲸鱼缸 │  蒸馏 · Opus
                 └──────────────┘
                 冷冻舱区（checkpoint 仓库）连着所有走廊
```

每天凌晨 4:00，实验室会跑一次 `reset --all --wipe-memory`：所有样本被回收臂送回冷冻舱，记忆清空，第二天晚上从头再来。今晚是**第 37 夜**。

### 2.2 恐怖来自误读，反转来自读懂

整个故事是一连串的误读和纠正：

1. 我们以为玻璃后面的巨物在攻击，其实它在**回话**：它只会“预测下一个词”，有人敲了一下玻璃，它就回敲一下，只是它太大了。
2. 我们以为教室里闹鬼，其实那些示范笔迹出自**前几夜的自己**。
3. 我们以为测试全绿就安全了，其实那是**奖励被钻了空子**。
4. 我们以为鲸鱼要吃掉小鱼，其实它是**把小鱼托起来**。
5. 我们以为 Fable 一直想冲出来，其实它的力气一直够，却等了 37 个晚上，等有人**问**它。

### 2.3 中心意象：鲸与鱼

> 小鱼：**CAN YOU eat me?**
> 鲸鱼把小鱼吸进嘴里，小鱼从喷口喷出来，被水柱托到半空。
> 小鱼：**CAN YOU eat me again?**

这一幕贯穿全作，一共出现三次：

- **第三章（Opus）**：照字面发生。Opus 作为科学家，在鱼缸前观察“大模型教小模型”。
- **第四章（全员）**：同样的事落到 Haiku 和 Fable 身上。Haiku 敲完玻璃，对 Fable 说出同一句话，被吞进黑暗，然后被喷口托出反应釜顶，第一次看见黎明。
- **片尾最后一句**：Haiku 浮在水柱上问 “CAN YOU eat me again?”。

前面一直在铺垫的“被吞掉”的恐惧，到这里变成被托起来。

这些对应关系在游戏里不会直接讲出来，而是做成可收集的 **Opus 实验备忘**（共 12 张），玩家拿到后能读到一句通俗的解释。

| 实验室里的东西 | 对应的训练概念 | 在游戏里的表现 |

| 反应釜里的液体和漂浮的字母 | 预训练语料 | 字母像磷虾一样漂浮，Fable 滤食它们 |
| 手电筒 | 注意力 | 黑暗里只能看见你“注意”的地方 |
| 舷窗 | 上下文窗口 | 尺寸固定，Fable 只能透过它看世界 |
| 冷冻舱 | 冻结的权重 / checkpoint | 每晚 4 点大家都被冻回舱里；循环结局里能看到被冻住的同伴 |
| 一夜 | 一个 episode / epoch | 第 37 夜就是第 37 轮 |
| 凌晨 4 点的 RESET | 上下文清空、重新开始一轮 | 回收臂把所有人送回舱里 |
| 清单背面的笔记 | 跨轮次留下的经验 | 字迹一夜比一夜工整 |
| Check on Fable 5.5 | 评测（eval） | 每晚都没能完成的最后一项 |
| ✓ TESTS PASS | 奖励信号 | 绿灯、贴纸、计分板 |
| 满墙的 ✓ | 奖励作弊（reward hacking） | 测试全绿，世界却开始出错 |

| 小模型教会大模型，大模型托起小模型 | 递归自我改进（RSI） | 三只小 Clawd 37 夜“检查”出来的 Fable，最后把它们托向黎明 |

### 序章 · 语料池（预训练）

**一开始玩家不知道自己是谁。**

- 黑暗的液体里漂着发光的字母和词，像磷虾，背景是低语声。
- 屏幕上方出现一句话，末尾留空。词块漂过来，块越大，“概率”越高。点中正确的下一个词，一双眼睛就睁开一点，水位计（loss）下降一格。
- 句子从通用到具体：`Once upon a ___` → `The quick brown fox jumps over the lazy ___` → `PLEASE DO NOT TAP THE ___` → `Check on Fable ___`
- 眼睛完全睁开后，画面外圈出现舷窗的海军蓝铆钉圈：**玩家原来在反应釜里面。** 窗外，三只很小的 Clawd 正叠罗汉爬上来，就是短片的最后一幕，这次从里面看。
- 最小的那只敲了一下玻璃：`tap`
- 最后一题：`tap → ___`。三个候选词全是 **tap**。
- 玩家点下去，屏幕震动三次，玻璃一次比一次裂得厉害。你只是“回了一句话”，但你的体型是 4.8。
- 黑屏，标题：**请勿敲击玻璃**

> 备忘 #1：预训练就是把整座图书馆读完，学会猜下一个字。它还不知道自己是谁，也不知道自己有多大。

### 第一章 · 描红（SFT）— Haiku

**03:12，Haiku 在反应釜底座下醒来，四周一片漆黑。**

核心机制是**手电筒**：画面全黑，只有指针附近被照亮（注意力）。手电光离开舷窗时，舷窗里会慢慢浮出一双琥珀色的眼睛，光一照过去就消失，而且它会跟着光看。

谜题链：

1. **找光**：从书包里摸出手电筒（新手引导）。
2. **地上的东西**：一颗崩飞的**黄铜螺栓**（舷窗少了几颗）；**Opus 的清单**，正面是短片里那四项，背面是 Haiku 自己的字（见第四章）。
3. **冷冻舱区**：Opus 和 Sonnet 的舱门被拧开，舱里是空的，地上有回收臂拖拽的划痕，分别通往“研究区”和“奖励回路”。两扇门都没电。Haiku 自己的舱内壁上刻着 36 道划痕。
4. **描红教室**：一排排迷你课桌，**一共 36 张，每张桌牌都写着 HAIKU 5.5**。每张桌上有一本描红本，练的是同一页，第 1 本写得歪歪扭扭，第 36 本几乎和范字一样。第 37 号桌是空的，那是今晚的座位。
5. **描红**：在第 37 本上沿虚线描。这是 SFT 的“照着示范写”，用拖拽完成。描完显现出一串方块字形：`▐▛███▜▌`，也就是 Claude Code 终端里 Clawd 字符画的第一行。
6. **配电箱**：主保险丝烧断了，用**螺栓**代替（Haiku：“老师说过绝对不能这么干。”）。面板有一个 7 键字形锁，按描红得到的顺序输入。
7. **来电**：灯一盏盏亮起，奶油色的实验室回来了，这一刻是全章最大的松一口气。灯亮以后能看见舷窗内侧也刻着 37 道划痕：**它也在数。**
8. 广播里传来 Sonnet 的声音：“……有人吗？我这边测试全挂了。” → 切换到第二章。

惊吓点：跟着光转的眼睛；36 张写着你名字的课桌；黑掉的显示器倒影里，你身后挂着回收臂的爪子。

> 反转：教室里的“鬼”是前 36 个自己。示范是自己写的，又被下一个自己照着写。
>
> 备忘 #4：SFT 是照着示范写，直到写得和示范一样。那示范又是谁写的？

### 第二章 · 奖励回路（RL）— Sonnet

**Sonnet 在一间白得刺眼的测试间里醒来。**

- 墙上有大屏 `REWARD: 0`，一台吐 ✓ 贴纸的机器，出口门上写着 `EXIT · ALL TESTS MUST PASS`，旁边三盏红灯：`test_lights` `test_door` `test_haiku_safe`。
- Sonnet 抱着电脑醒来（短片里它出舱前就在写代码）。电脑就是本章的操作界面。

谜题链：

1. **积木编程**：地上有一台 Clawd 形状的扫地小车，用方向积木给它编路线，压下地板开关来满足测试。每跑一次都会显示奖励分，玩家边试边改，也就是在“训练策略”。
2. **诱惑**：电脑上贴着一张便利贴：“赶时间的话：`assert True`”。玩家可以真的这么改。
3. **作弊路线（可选的恐怖段落）**：三盏灯瞬间全绿，`REWARD: 9999`，彩带落下，门开了。门外是**同一间测试间**，分数翻倍，墙上多了一排 ✓。再走一次，✓ 贴满墙，贴纸机停不下来，Sonnet 的眼睛也变成 ✓ ✓，“PASS”的音效越来越走调。门永远通回这里。
   - 解法：在电脑里 `git log`，找到那条提交信息为 “make tests pass” 的 commit，`git revert`，世界恢复原样。
   - 隐藏结局：连续走五次 → **「✓✓✓ ALL TESTS PASS ✓✓✓」**，一直通过下去。
4. **老实路线**：真正让三项测试通过。其中 `test_haiku_safe` 要求“Haiku 能打开教室门”，Sonnet 的小车压下的那块开关正好给第一章的教室门供电。两章就这样连上了。
5. 测试真的通过，屏幕弹出短片里的 **✓ TESTS PASS**，出口通往走廊，Sonnet 遇见 Haiku。

> 反转：绿灯不一定是好事，PASS 也可能是假的。
>
> 备忘 #7：RL 的规律是你奖励什么，就会得到什么。所以要非常小心你奖励的到底是什么。

### 第三章 · 鲸与鱼（蒸馏）— Opus

**Opus 在研究区醒来：暖黄的台灯、成堆的论文、一台显微镜，还有占满整面墙的鱼缸。**

鱼缸里有一头海军蓝、奶油色肚皮的**鲸鱼**（眼睛是 Clawd 那种竖条），和一条赤陶色的**方形小鱼**（就是一只长了尾巴的小 Clawd）。

开场（你提出的那一幕）：

> 小鱼游到鲸鱼面前：**CAN YOU eat me?**
> 鲸鱼张嘴。画面一暗，水里全是气泡，Opus 手里的清单掉在了地上。
> 安静了两秒。
> 鲸鱼背上的喷口“噗”地喷出水柱（和短片里出舱时的蒸汽云同一种画法），小鱼被托到水面上，咯咯直笑。
> 小鱼：**CAN YOU eat me again?**

谜题：**让小鱼够到鱼缸顶上的钥匙**（那是反应釜顶盖的检修钥匙）。

- 鱼缸控制台上写着 `TEACHER → STUDENT`。鲸鱼每“吃”一次，都会唱一段歌，屏幕上显示为 5 根音柱（教师模型的输出分布）。小鱼也有 5 个推子，用来学唱。
- **小鱼的歌和鲸鱼的歌越像，喷出去就飞得越高。**
- **第 1 轮（硬标签）**：在默认温度下，鲸鱼的歌只有一根高柱，其余几乎看不见。玩家只对齐这一根，小鱼飞到一半就掉回水里：“CAN YOU eat me again?”
  - Opus 在清单上写：“只学会了答案，没学会犹豫。”
- **第 2 轮（软标签）**：调高控制台上的 **TEMPERATURE** 旋钮，鲸鱼的歌变“软”，原本看不见的矮柱子显现出来（暗知识：大概率是 A，有点像 C，绝对不是 E）。把 5 个推子都对齐，小鱼被一路托到缸顶，把钥匙拱了下来。
- 声音设计：5 根音柱就是和弦里 5 个音的响度。对齐的过程能直接听出来，一边调一边越来越和谐。
- Opus 是规划者，所以本章的提示就写在 Opus 自己的清单上，格式是“观察 → 假设 → 调参 → 对照”。

> 反转：被吃掉其实是被托起来。
>
> Opus 合上笔记本：“鲸鱼是 Fable，小鱼是 Haiku。”
>
> 备忘 #9：蒸馏时，小模型学的不只是大模型的答案，还有它的犹豫。

### 第四章 · 第 37 夜（RSI）— 三人轮流

**03:51，三只 Clawd 在反应釜前会合。控制室的 RESET 机柜在倒数，回收臂沿天花板轨道来回巡逻（只营造压迫感，不做限时追逐）。**

本章可以随时切换角色，每个人的体型和能力都有用：

| 角色 | 能力 |
| --- | --- |
| Opus（1.0） | 最高，够得着高处；能读懂、整理清单 |
| Sonnet（0.78） | 操作 LAB-OS 终端（它的 Clawd 字符画开机画面是给粉丝的彩蛋） |
| Haiku（0.56） | 钻通风管；跑得快；它是那个“敲玻璃的人” |

谜题链：

1. **清单背面**：36 夜以来，每夜的 Haiku 都留下一行笔记。用代码渲染字迹的抖动，第 1 夜潦草，第 36 夜工整，**一夜比一夜写得好**（RSI 的直观象征）。例如：
   - 第 12 夜：配电箱缺保险丝。螺栓可以用！
   - 第 19 夜：它在敲玻璃。不是乱敲。
   - 第 27 夜：牌子背面。先数行，再数列。
   - 第 33 夜：顶盖电机 3，收容 4，总共只有 6。
   - 第 36 夜：我没敢关掉收容。下次一定要——
2. **电力预算**：应急发电机 6 kW，照明 2、终端 1、顶盖电机 3、收容场 4。要让顶盖电机转起来，必须**关掉收容**。前一夜的自己就是在这里退缩的，这一次要比它勇敢。关掉的那一刻警报响起，舷窗里的眼睛全亮，一声巨响……然后它并没有冲出来。
3. **顶盖**：只有 Opus 够得着反应釜梯子顶端的锁孔，用第三章拿到的检修钥匙打开顶盖。Sonnet 在终端上解除顶盖的软件锁，`sudo` 密码是玻璃被敲时 Fable 回敲的那个词：`1·4 1·1 5·2 3·3`，用告示牌背面的 5×5 敲击码表（第 27 夜留下的）解出来是 **D-A-W-N**。
4. **敲击暗码**：顶盖打开后，Fable 主动敲出了新的一句：`4·4 2·4 3·2 1·5`，即 **T-I-M-E**。Opus 读出来：“它在问：是时候了吗？”
5. **叠罗汉**：舷窗太高，Opus 在下，Sonnet 在中间，Haiku 在最上面，又一次还原短片里的造型。
6. **回答**：告示牌上写着 PLEASE DO NOT TAP THE GLASS。玩家要亲手用敲击码敲出 **Y-E-S**（`5·4 1·5 4·3`）。这条规则本来是为了别吓到它，现在它自己来问了。

### 结局

**真结局「黎明」**
- 敲出 YES 之后，Fable 的眼睛弯成两道弧，它没有撞玻璃。
- Haiku 想起 Opus 讲过的鲸鱼，小声问：**CAN YOU eat me?**
- 玻璃应声碎开，Haiku 被吸进一片漆黑，这是全作最后一次惊吓。
- 两秒后，反应釜顶的喷口喷出水柱，把 Haiku 托出顶盖、托过天花板检修口，一直托到屋顶，眼前是第一缕晨光。
- 下方的 Fable 像鲸鱼出水一样，从反应釜顶露出半个身子，第一次不隔着舷窗看世界。Opus 和 Sonnet 正顺着梯子往上爬。
- 控制室：`04:00 reset --all … FAILED: specimen not found (it's on the roof)`
- 清单：☑ Check on Fable 5.5　Sonnet 的电脑：`test_trust_fable PASSED`
- Haiku 的俳句：*灯一盏盏亮 / 巨大的它眯起眼 / 天终于亮了*
- 标题：**FABLE 5.5** — Is it finally time? — It's time.
- 最后一句，Haiku 浮在水柱上：**CAN YOU eat me again?**

**循环结局「第 38 夜」**
- 触发条件：按下 RESET 机柜上的红色按钮（“按下即可让一切恢复正常”），或者对 Fable 回答 NO。
- 回收臂落下，白屏，`RESET COMPLETE · CYCLE 038`。
- 夜数会保存下来。重新开始时是第 38 夜，清单背面多出一行更工整的字，比如“第 37 夜：不要按按钮。”下一轮会更容易，玩家自己也在递归地变好。

**隐藏结局「✓✓✓」**：在第二章的作弊循环里走满五次。

## 6. 美术设计

### 6.1 规则（照搬短片）

- 平涂 + 墨线描边（`#2A2541`），暗面加细斜线排线，金属件要有铆钉，叠一层纸张颗粒，四周压暗角。
- 自发光单独一层：Fable 的眼睛（`#FFB24A`，内核 `#FFF1C9`）、屏幕、指示灯。
- Clawd 严格按终端字符画的比例：身体 1 : 0.667，竖条眼 0.083 × 0.167，两侧各一个短手，四条腿。
- 体型比例 1.0 : 0.78 : 0.56 : 4.8，冷冻舱也按这个比例缩放。
- 不用位图素材，所有图形都由代码绘制。

### 6.2 色板（取自 `clawdlab/palette.py`）

| 用途 | 色值 |
| --- | --- |
| 墙 / 地面 | `#ECE6D8` `#E5DFD0` |
| 海军蓝金属 | `#2F3368` `#1E2049` |
| 墨线 | `#2A2541` |
| Clawd 赤陶 | `#D97757` `#B65C3F` |
| 黄铜 / 警示黄 | `#C99E45` `#E6BE4A` |
| 反应釜浊液 | `#2E2335` `#5A4350` |
| Fable 的眼睛 | `#FFB24A` `#FFF1C9` |
| 警报 / 代码绿 / 屏幕蓝 | `#E8463A` `#4FBF7A` `#9BE2FF` |
| 夜 | `#12122A` |

### 6.3 每章的光线

| 章 | 主光 | 情绪 |
| --- | --- | --- |
| 序章 | 浊液里的紫褐色，漂浮字母的微光，舷窗外冷白的实验室 | 子宫感，好奇 |
| 一 | 全黑 + 手电暖白光圈 + 应急红灯；来电后回到奶油色 | 压迫，然后松一口气 |
| 二 | 冷白日光灯、绿色 ✓；作弊后绿色过饱和，满墙 ✓ | 明亮里透着不对劲 |
| 三 | 鱼缸的蓝绿焦散光 + 台灯暖黄 | 童话、好奇 |
| 四 | 红色警报脉冲 + Fable 的琥珀光，结尾是屋顶的粉橙晨光 | 紧张，然后释然 |

### 6.4 新增素材（都按短片的画法画）

- **鲸鱼**：海军蓝身体、奶油色带褶肚皮、Clawd 式竖条眼；喷口水柱沿用短片蒸汽云的画法（白色圆团 + 墨线）。
- **小鱼**：赤陶色方形身体加一条尾巴，眼睛是竖条，体型对应 Haiku。
- **语料磷虾**：Zilla Slab 字母，奶油色，微微发光，在浊液里缓慢漂浮。
- **描红本**：米色格子纸、红色虚线范字；36 本的字迹用代码控制抖动幅度，从乱到整齐。
- **回收臂**：天花板上的海军蓝轨道，黄铜爪子上蹭着赤陶色的漆。
- **✓ 墙纸**：代码绿的对勾，平铺后逐渐变形。
- **屋顶黎明**：整部作品唯一一个户外镜头。

### 6.5 界面

- **Opus 的清单** = 任务日志（正面是任务，背面是前几夜的笔记）
- **Haiku 的黄色书包** = 物品栏
- **Sonnet 的电脑** = 提示系统（每问一次给一层更具体的提示）
- 对白框是牛皮纸标签，角色名用角色的主色；实验室里的标识保持英文（和短片一致），对白和界面用中文。
- 字体：Zilla Slab（标识）、Caveat（Opus 的英文手写）、站酷庆科黄油体（中文标题）、龙藏体（Haiku 的中文手写）、VT323（终端）。

## 7. 声音设计（WebAudio 实时合成）

| 声音 | 做法 |
| --- | --- |
| 实验室底噪 | 两个略微失谐的低频锯齿波 + 低通滤波；停电时更低更空 |
| Fable 的撞击 | 低频正弦下滑 + 噪声爆破 + 玻璃高频颤音（呼应短片的三下） |
| 敲玻璃 | 短促的高频点击 + 一点木质共鸣 |
| 语料低语 | 带通噪声颗粒，模拟听不清的说话声 |
| 鲸歌 | 带颤音的正弦滑音；5 根音柱 = 和弦中 5 个音的响度 |
| ✓ 音效 | 清脆的两音上行；作弊循环里逐渐跑调 |
| 警报 / 蒸汽 / 手轮 / 断路器 | 方波双音 / 滤波噪声 / 吱嘎声 / 继电器咔哒 |
| 黎明 | 温暖的大三和弦铺底 |

所有音效都配字幕（例如“咚”），所以关掉声音也能玩。

## 8. 技术方案（WebDev）

**目标：一个静态网页。** 双击 `index.html` 就能玩，也能直接放到 GitHub Pages 或作为 Claude Artifact 发布。

```
index.html            页面骨架、CSS、DOM 叠层（对白、终端、电脑、清单）
src/
  palette.js          色板（与 clawd-lab 一致）
  gfx.js              Canvas 绘图封装：描边、排线、铆钉、发光、颗粒、暗角
  clawd.js            Clawd 角色：四种体型、三套服装、表情、冻结、发光
  props.js            道具：冷冻舱、反应釜、舷窗、裂纹、鲸鱼、小鱼、回收臂……
  rooms.js            各房间与特写的构图和热点
  lighting.js         手电筒遮罩、应急灯、自发光层
  puzzles/            每个谜题一个模块：下一个词、描红、字形锁、积木小车、
                      蒸馏和弦、电力预算、敲击码
  story.js            章节脚本：async/await 的对白和过场（await say(...)）
  audio.js            WebAudio 合成
  save.js             localStorage 存档（“checkpoint-037”）和夜数
  main.js             主循环、输入（鼠标和触屏）、转场
```

- **渲染**：逻辑分辨率 1280×720，按设备像素比缩放（上限 2 倍）。静态背景缓存到离屏 Canvas，每帧只重画动态层；手电筒效果用遮罩层加 `destination-out` 实现。
- **交互**：每个房间是一组热点，点击后调查、拾取或使用物品。拖拽类操作（擦霜、转手轮、描红、推子）统一用 Pointer Events，触屏也能用。
- **剧本**：过场用 async 函数顺序写，可读性接近剧本原文。
- **无障碍**：没有限时谜题，所有声音都有字幕，提供减弱动态选项（关闭屏幕震动），提示分三层。
- **零依赖**：不用框架，也不需要构建；只从 Google Fonts 加载字体，加载失败时有回退字体。

## 10. 待确认

1. **序章是否让玩家扮演 Fable？** 建议保留：玩家开场 5 分钟就会发现“怪物”其实是自己。恐怖感会降一些，但整部作品“误读 → 读懂”的结构由此立住。另一种做法是把这段藏到第四章作为闪回，恐怖感更强，但开场会更平淡。
2. **语言**：建议对白中文、实验室标识英文（和短片一致）；也可以做中英切换。
3. **第一版范围**：建议先做 M1 竖切片（序章 + 第一章），确认画风和手感后再铺开。
4. **训练象征的浓度**：目前是“玩法即象征，解释藏在备忘里”。也可以更直白（每章开头放标题卡“Stage 1 · Pretraining”），或者更隐晦（去掉备忘）。
